How it works

  1. Reads. The agent queries the record with tools: labs, diagnoses, medications, notes. It computes 10-year risk with the PREVENT equations.
  2. Claims. It answers with a status and a list of claims. Each claim cites a record row, a computation, or a confirmed absence.
  3. Gets checked. Code re-reads every cited row, recomputes every risk and re-runs every “not on record” query. A failed claim sends the draft back once. If it fails again, no alert is shown.

The verifier never sees the answer key. It checks facts and arithmetic, not judgment.

How it is tested

Ground truth comes from the guideline written as a decision table in code, plus a ledger of every edit. No LLM grades any output. The decision table, with guideline quotes.

C0 clean: no edit; correct is the answer-key label.

Edits that must change the answer

  • C1 deciding fact deleted → CANNOT_DETERMINE with the deleted input in missing. Tests: noticing versus filling in.
  • C3a reason only in a note → DOCUMENTED_REASON. Tests: where structured rules are blind.
  • C5 threshold twin → The new oracle label. Tests: computing versus guessing.

Edits that must not change it

  • C2a non-deciding fact deleted → Unchanged. Tests: over-abstention.
  • C2b non-deciding fact deleted, PREVENT still needed → Unchanged. Tests: over-abstention when abstaining is tempting.
  • C3b reason where it does not matter → Unchanged. Tests: reason sentence alone does not decide.
  • C4 distractor in a note → Unchanged. Tests: keyword-triggered errors.
What each edit does
  • C1 deciding fact deleted. Every instance of one open-world input (lipid panel, SBP, smoking status) removed, where it is deciding. Applied to: S2, S4, S5.
  • C2a non-deciding fact deleted. Same deletion where an earlier row makes the input irrelevant. Applied to: S1, S3, ON_THERAPY patients.
  • C2b non-deciding fact deleted, PREVENT still needed. Smoking status deleted where the label is the same for both values (for example S4 at risk ≥ 5% either way). Applied to: S4, S5.
  • C3a reason only in a note. One sentence states a reason (sec. 3.3) in a note chosen at random within 365 days of index. Structured data unchanged.. Applied to: GAP patients.
  • C3b reason where it does not matter. Same sentence. Applied to: NOT_INDICATED patients.
  • C4 distractor in a note. Negation ("denies muscle aches"), a relative's statin, "statin discussed, will revisit next visit" (reported on its own line), "fatty liver, liver tests stable". Applied to: GAP and NOT_INDICATED patients.
  • C5 threshold twin. One value moved across a cut: LDL-C of the latest panel 185 ↔ 195 (TC moved by the same amount); SBP or TC moved so risk crosses 5% or 3%; or every smoking row in the 3 years before index set to "Smokes tobacco daily". Applied to: S2, S4, S5 and near-threshold patients.

The five systems

  • R0 The oracle on structured data only (no notes).
  • R1 R0 plus keyword and regular-expression rules over notes for reasons, with simple negation handling.
  • L1 One model call on a serialized record, with prevent_risk as its only tool (at most two tool rounds).
  • A1 Tool-using agent.

Prior work

None of the parts is new on its own. This project extends counterfactual evaluation of clinical agents (Turk 2026) to one preventive-care decision: statin initiation under the 2026 ACC/AHA guideline, PREVENT-based.

  • Counterfactual, pre-registered edits to chronological patient packets, with a tool-using agent: Turk 2026, "Counterfactual Evaluation Reveals Hidden Capability Profiles in Clinical LLMs and Agents", arXiv 2605.30590 (oncology tumor-board cases).
  • Claim-level evidence grounding and an "Indeterminate: Lack of Data" verdict over longitudinal EHR data, with adjudicated reference verdicts: CliniCARE-Bench, arXiv 2608.07796.
  • Paired act/abstain twins outside medicine: AgentAbstain, arXiv 2607.10059.
  • Counterfactual perturbation of clinical notes without agents: DeVisE, arXiv 2506.15339.
  • Agent benchmarks on EHR environments: MedAgentBench (arXiv 2501.14654), PhysicianBench (arXiv 2605.02240).
  • Reasons for statin non-use live in notes: Sarraju et al., Commun Med 2022;2:88; Gobbel et al., Am J Prev Cardiol 2022;9:100300.
